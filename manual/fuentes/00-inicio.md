# Cómo usar este manual {#como-usar .sin-numero}

Este manual explica cómo usar NeuroDatics para crear proyectos, cargar los datos de un experimento, analizarlos y generar informes. Está pensado para investigadores, docentes y estudiantes que ya tienen la aplicación abierta en el navegador. Cómo instalar NeuroDatics o abrirlo por primera vez está en la guía de instalación de cada edición.

### Cómo está organizado

- **Si es tu primera vez**, lee [[ref:cap-conocer]] y sigue [[ref:cap-recorrido]]: en unos minutos tendrás tu primer informe.
- **Si buscas una tarea concreta**, empieza por «Tareas frecuentes» o por el contenido.
- **Si quieres entender lo que muestra una gráfica**, ve a [[ref:cap-entender]].
- **Si algo no funciona**, ve a [[ref:cap-problemas]].

### Convenciones

<!-- anchos: 30 70 -->
| Así se ve | Qué significa |
| --- | --- |
| **Guardar cambios** | Un botón, pestaña, campo u opción de la pantalla, escrito tal como aparece. |
| «Cambios guardados.» | Un mensaje que muestra la aplicación. |
| «Estadísticas» | El título de una tabla, tarjeta o recuadro de la pantalla que no se pulsa. |
| `eliminar` | Algo que escribes tú, o el nombre de un archivo o carpeta. |
| {servidor} | Solo existe en la edición servidor (con cuenta de Google). |
| {estudiantes} | Solo existe en la edición estudiantes (un computador, sin internet). |

En las imágenes, el **recuadro rojo** y la **flecha** señalan dónde debes mirar o hacer clic. Cuando una imagen señala varios puntos, aparecen numerados (1), (2) y (3), y los pasos citan el mismo número. Las imágenes usan datos de demostración inventados. Las referencias «Ver…» remiten a otra sección; en el documento digital puedes hacer clic en ellas.

El manual usa tres tipos de aviso:

::: nota
Información útil que conviene saber, pero que no cambia el resultado.
:::

::: consejo
Un atajo o una buena práctica para trabajar mejor.
:::

::: importante
Algo que puede hacerte perder trabajo o sacar conclusiones equivocadas.
:::
