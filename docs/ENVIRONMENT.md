# ENVIRONMENT.md

## Frontend

Variables requeridas:

- NEXT_PUBLIC_API_BASE_URL
- NEXT_PUBLIC_GOOGLE_CLIENT_ID

Variables opcionales (acceso admin local):

- NEXT_PUBLIC_DEV_ADMIN_EMAIL
- NEXT_PUBLIC_DEV_ADMIN_PASSWORD
- NEXT_PUBLIC_DEV_ADMIN_DISPLAY_NAME

Ejemplo de frontend/.env.local:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
NEXT_PUBLIC_GOOGLE_CLIENT_ID=
NEXT_PUBLIC_DEV_ADMIN_EMAIL=
NEXT_PUBLIC_DEV_ADMIN_PASSWORD=
NEXT_PUBLIC_DEV_ADMIN_DISPLAY_NAME=Administrador NeuroDatics
```

## Backend

Definidas en backend/.env.example:

- DATABASE_URL
- GOOGLE_OAUTH_CLIENT_ID
- GOOGLE_OAUTH_CLIENT_SECRET
- GOOGLE_OAUTH_REDIRECT_URI
- GOOGLE_OAUTH_TOKEN_URL
- GOOGLE_OAUTH_USERINFO_URL
- AUTH_JWT_SECRET
- AUTH_JWT_ALGORITHM
- AUTH_JWT_ISSUER
- AUTH_ACCESS_TOKEN_EXP_MINUTES
- AUTH_REFRESH_TOKEN_EXP_MINUTES
- AUTH_USER_STORE_PATH
- GOOGLE_APPLICATION_CREDENTIALS
- GDRIVE_SERVICE_ACCOUNT_JSON
- GDRIVE_FOLDER_ID
- APP_NAME
- DEBUG

## Recomendaciones De Seguridad

- No commitear .env con secretos reales.
- Rotar AUTH_JWT_SECRET en cada entorno.
- Mantener GOOGLE_OAUTH_CLIENT_SECRET solo en backend.
- Evitar publicar GDRIVE_SERVICE_ACCOUNT_JSON en repositorios.
- Limitar CORS y DEBUG en produccion.
